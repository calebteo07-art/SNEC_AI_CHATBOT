## CURRENT RULES (v2 — supersede all v1 frozen rules)
- **Palette**: PHOTOPIC tokens only (`src/styles/index.css` + `eyebot.css`). Legacy var NAMES preserved (`--teal` = brand blue, `--purple`, `--emerald`, `--cyan` OA, `--gold #d97706`). Tracks: OA cyan / OT violet / PSA emerald (`lib/legacy/trackColors.ts`). No new hues outside the gem spectrum + ink/paper.
- **Typography**: DM Sans (UI/body) + Instrument Serif 400/italic (display accents) + JetBrains Mono (readouts) — all **next/font self-hosted** (`app/layout.tsx`); fluid steps `--step--1..--step-6` in index.css.
- **Canvas law**: fluid background canvas (z-0, `fx/canvas/FluidCanvas.tsx`, frameloop=never stepped by the shared gsap ticker) + GazeIris canvas on login only (own R3F canvas) + LiquidImage **pooled per-tile contexts, max 3, hover-steal, plain `<img>` always beneath** (per-tile is deliberate: a global overlay canvas would paint over the chips that sit on card imagery). Budgets: fluid sim ≤128px / dye ≤720px / dpr 1.5 / 20 Jacobi / idle-stop 6s + task-route pause; gaze dpr ≤2.
- **z-map**: fluid 0 < content 10 (providers wrapper) < chrome 20+ < GuidedTour 100–103 < shutter 220 < **preloader 400**.
- **Engine boundary (D4)**: GSAP owns timelines/scroll/text (preloader, `(shell)/template.tsx` enter, ScrollTrigger scrub, SplitText, Magnetic quickTo, fluid stepping via `fx/ticker.ts` = gsap.ticker, lagSmoothing(0)); motion@12 stays ONLY for pre-existing component micro-interactions — **no new `motion/react` imports inside `fx/`**.
- **Scroll**: custom div-scroller `ScrollProvider` (Lenis), route exclusions verbatim: **never on `/chat`, `/flashcards`, `/cases/:id`, `/admin/*`**. ScrollTrigger bridged via `scrollerProxy` + `lenis.on(scroll, ScrollTrigger.update)`. Scrollytelling pins use **CSS sticky** (never ScrollTrigger pinning) inside the scroller.
- **Reduced motion** (OS media query OR profile toggle `localStorage["eyebot_motion"]`, mirrored to `html[data-motion]`): zero fluid canvas, static iris frame, plain text, instant cuts, posters instead of loops, confetti disabled (`fx/confetti.ts` wrapper — always use it, never raw canvas-confetti).
- **A11y invariants**: exactly one h1/route, `main/nav/header` landmarks, every canvas aria-hidden, SplitText = aria-label parent + aria-hidden fragments, `:focus-visible` brand-blue ring, no horizontal overflow at 390×844 (all verified programmatically).
- **Generative media**: assets resolve from `/media/manifest.json` (versioned; `tools/media/build_manifest.py`); **generation never blocks a user**. Every model-emitted SVG passes `tools/media/sanitize_svg.py` **fail-closed at generation time** AND renders via `<img>` only. Gemini sweeps (`generate_accents.py`) and Higgsfield loops (`ingest_loops.py`, operator CLI) are **paid — confirm with the user before running**. Admin → "Refresh media" queues the Celery `media` queue.
- **Auth/nav**: `src/proxy.ts` (Next 16 middleware rename) does cookie-presence 307 only; real authz = client guards per page (CheckInGuard per screen; AdminGuard in admin layout WITHOUT CheckInGuard) + API JWT. `TransitionProvider` keeps the v1 wipe/handoff promise API; covers: paper shutters w/ gem seam, **ink cover for the login engulf** (`data-cover`). The login screen suppresses its signed-in redirect during login choreography (`loggingInRef` — App Router async-nav race).
- Sound: synth-only Web Audio, master 0.13, mute persisted `localStorage["eyebot_fx_muted"]`, auto-muted under reduced motion.
