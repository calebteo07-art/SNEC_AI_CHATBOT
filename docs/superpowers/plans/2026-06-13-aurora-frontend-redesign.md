# AURORA Frontend Redesign — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Strip and rebuild the entire EyeBot frontend in the AURORA design language (light, Gemini gradient, Google Sans, monochrome Spark Eye, Atlas Rail nav, realistic eye imagery) while keeping the login screen and the FastAPI backend untouched.

**Architecture:** Keep the Next.js 16 (App Router) + Tailwind v4 + TanStack Query foundation. Replace the PHOTOPIC token layer, fonts, navigation shell, and every screen. Remove the heavy `src/fx/` WebGL/scroll layer (fluid sim, liquid tiles, preloader, Lenis, R3F) and replace it with one lightweight animated-gradient surface driven by a single GSAP ticker. Realistic imagery is generated by Gemini Nano Banana Pro into the existing `/media` manifest pipeline.

**Tech Stack:** Next.js 16.2.1 · React 19 · TypeScript (strict) · Tailwind v4 (postcss) · GSAP 3.15 · TanStack Query 5 · Playwright (visual + behavioural checks). Backend unchanged: FastAPI on 127.0.0.1:8000 proxied via Next.

**Source of truth:** the design spec at `docs/superpowers/specs/2026-06-13-frontend-redesign-design.md`.

---

## Conventions for this plan

- **Working dir:** `frontend/` for all `npm` commands. Repo root for git.
- **Verification loop (frontend-adapted TDD):** there is no unit-test runner in this repo; the
  test harness is Playwright (`frontend/tests/`). For each screen/component the loop is:
  **(1)** write/extend a Playwright assertion that fails → **(2)** build the component →
  **(3)** run the assertion until it passes → **(4)** capture a screenshot via the visual sweep →
  **(5)** `npm run typecheck` clean → **(6)** commit + push.
- **Dev servers for checks:** backend `uvicorn tools.api.server:app --port 8000` (repo root) +
  `npm run dev` (frontend, :3000). Playwright sweeps mock the API, so the backend is optional for
  visual checks but required for SSE/login smoke tests.
- **Standing rules:** commit + push after every phase; never overwrite files in `workflows/`
  without explicit user permission; **Nano Banana generation is PAID — confirm with the user
  before running any generation command** (Phase 8).
- **Reduced motion** must be honoured by every animated element from the moment it is created.

## File Structure (decomposition)

**New foundation (`frontend/src/aurora/`)** — the new design system lives in one folder so it is
easy to reason about and the old `fx/` can be deleted wholesale:
- `aurora/tokens.css` — AURORA CSS custom properties (imported by `styles/index.css`).
- `aurora/Logo.tsx` — monochrome static Spark Eye mark + wordmark lockup (`currentColor`).
- `aurora/MotionSurface.tsx` — animated-gradient wrapper + the shared GSAP gradient loop + the reduced-motion hook.
- `aurora/motion.ts` — `useReducedMotion()` + the single ticker that advances `--aurora-pos`.
- `aurora/icons.tsx` — `GlyphIcon` vector control set (close, back, send, chevron, menu, attach, search, plus).
- `aurora/components/` — `AtlasRail.tsx`, `CommandPalette.tsx`, `GradientHero.tsx`, `StatCard.tsx`, `PlateWell.tsx`, `AtlasMap.tsx`, `CaseCard.tsx`, `TrackChips.tsx`, `ChatThread.tsx`, `MessageBubble.tsx`, `Composer.tsx`, `FollowupChip.tsx`, `FlashCard.tsx`, `Sparkline.tsx`, `Heatmap.tsx`, `ProgressBar.tsx`.

**Rebuilt shells/pages** — existing files under `frontend/src/app/(shell)/**` and `frontend/src/screens/**`.

**Deleted** — `frontend/src/fx/**` (heavy layer), and R3F/Lenis/three usages.

**Verification** — `frontend/tests/aurora_assert.mjs` (new behavioural assertions) + the existing `frontend/tests/visual_sweep.mjs` (screenshots).

- [ ] **Step 1: Reduced-motion hook + CSS keyframes**

`frontend/src/aurora/motion.ts`:
```ts
"use client";
import { useEffect, useState } from "react";

export function useReducedMotion(): boolean {
  const [reduce, setReduce] = useState(false);
  useEffect(() => {
    const mq = window.matchMedia("(prefers-reduced-motion: reduce)");
    const stored = localStorage.getItem("eyebot_motion") === "reduce";
    const apply = () => {
      const r = mq.matches || localStorage.getItem("eyebot_motion") === "reduce";
      setReduce(r);
      document.documentElement.dataset.motion = r ? "reduce" : "";
    };
    apply();
    mq.addEventListener("change", apply);
    window.addEventListener("storage", apply);
    return () => { mq.removeEventListener("change", apply); window.removeEventListener("storage", apply); };
  }, []);
  return reduce;
}
```
Add to `styles/index.css`:
```css
@keyframes aurora-flow { 0% { background-position: 0% 50%; } 100% { background-position: 200% 50%; } }
.aurora-flow {

  background-size: 200% 100%;
  animation: aurora-flow var(--aurora-anim) linear infinite;
}
html[data-motion="reduce"] .aurora-flow { animation: none; }
```
