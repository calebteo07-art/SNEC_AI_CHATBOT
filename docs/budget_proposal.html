1. Executive Summary

EyeQ is a web-based AI tutoring platform built exclusively for ophthalmology trainees at SNEC. The system delivers interactive Socratic tutoring, clinical case simulations, spaced-repetition flashcards, a retinal image quiz module, and a daily check-in system — all powered by Google's Gemini AI models. A supervisor dashboard provides faculty with real-time cohort performance analytics and at-risk student identification.

This document provides a transparent cost breakdown for two budget categories: (1) development tooling costs using Claude AI by Anthropic for a single developer over a four-month build period, and (2) ongoing operational API costs for 100 student users over a 12-month period. Pricing figures are drawn directly from official vendor pricing pages, with evidence references provided in the appendix.

4. Operational Cost — Google Gemini API

All AI inference in EyeQ is handled by Google's Gemini API, billed on a per-token basis. Two model tiers are used: Gemini 2.5 Flash for complex multi-turn reasoning tasks (tutoring, case simulation, image analysis, study suggestions) and Gemini 2.5 Flash-Lite for lightweight generation tasks (flashcard creation and case evaluation scoring).

4.2 Usage Assumptions

Token counts account for all application features across the full stack, including system prompt overhead and Gemini 2.5 Flash's internal reasoning (thinking) tokens, which are billed at the standard output rate. The following assumptions drive annual cost projections.

Table 4.2 — Usage Assumptions
ParameterValue
Target user cohort100 users
Average sessions per user per week4 sessions
Weeks per year52 weeks
Total sessions per year (all users)20,800 sessions
Flash input tokens per session~28,000 tokens
Flash output tokens per session (incl. thinking tokens)~18,700 tokens
Flash-Lite input tokens per session~2,000 tokens
Flash-Lite output tokens per session~600 tokens

Token overhead notes: Input tokens are higher than a naive per-turn estimate because (a) each API call carries the full conversation history plus a detailed ophthalmology system prompt (~4,000–5,000 tokens), and (b) all 8 application features make API calls within a session. Output tokens include Gemini 2.5 Flash's chain-of-thought reasoning (thinking) tokens, which are billed at the standard output rate of $2.50/1M and are not visible in the final response but are charged. Flash-Lite is used only for flashcard generation and case scoring — shorter, simpler calls without extended reasoning.

A.3 — Token Usage Methodology

Token counts in Section 4.2 are empirically derived from a representative full-session run using the Gemini API's native usage metadata fields (promptTokenCount and candidatesTokenCount). The session covered all application features:

  • Tutor Chat — 10 Socratic dialogue turns with student profile context
  • Case Simulation — Full walkthrough (5 patient interaction turns + structured evaluation)
  • Image Quiz — 1 fundus image analysis question with student description
  • Daily Check-In — AI-generated question + response evaluation
  • Study Suggestion — AI-generated recommendation based on student profile
  • Flashcard Generation — Post-session extraction of Q&A pairs (Flash-Lite)
  • Case Evaluation Scoring — Rubric-based scoring against case answer key (Flash-Lite)

Detailed token logs from the measurement session are available on request. The 20% safety buffer is applied to account for session length variability, model prompt overhead changes between API versions, and occasional retries on API errors.
