## 9. GOTCHAS & CONSTRAINTS
- **HARNESS (frontend) — two traps that already bit this session:** (1) `bash scripts/start-harness.sh
  aurora` REUSES a server already on :3000 and SKIPS the rebuild → asserts against a STALE bundle
  ("token not defined" false-fail). If a prior run/subagent left an orphaned `node` server, kill it:
  PowerShell `(Get-NetTCPConnection -LocalPort 3000 -State Listen).OwningProcess | %{Stop-Process -Id $_ -Force}`,
  then re-run. `start-harness.sh stop` only kills a server IT started. (2) NEVER judge pass/fail by a
  piped exit code (`… | tail` returns tail's 0) — read the printed `HARNESS_EXIT=`/`PASS:`/`FAIL:` lines.
