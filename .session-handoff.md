  tool and the PowerShell tool **share one persisted working directory**, and it persists on
  a command's exit-0. A `cd tools` inside a Bash compound command moved the shared cwd to
  `tools/`, which then (a) broke the `bash_guard.py` PreToolUse hook — it resolves
  `.claude/hooks/bash_guard.py` RELATIVE to cwd, so from `tools/` it can't find its own script

  PowerShell tool (resets the shared cwd; Bash recovers immediately). **Prevention:** never
  `cd` into a subdir in a Bash compound command — use absolute paths, and for git prefer
