  constraint; may be gently reconciled later (logo swap) but no structural change without asking.
- **Strip depth:** rebuild from zero (rethink screens, not a reskin). Only login + backend sacred.
- **Cut nothing:** all features survive, redesigned — Dashboard, Tutor(chat), Cases, Flashcards,
  Progress, Summary, Daily check-in, gamification, Profile, Admin(overview/students/accounts/
  activity), Supervisor.
- **Platform:** desktop-first, adapts down to mobile.
- **Personality:** cinematic/futuristic + editorial/academic. **References:** Linear/Vercel + Apple.
- **Centerpiece:** no single hero — the navigation model is the star.
- **Chosen art direction:** direction "A · Nocturne Atlas" (editorial medical-atlas structure)
  **remixed to LIGHT MODE + Google Gemini theme**, codename **AURORA**.
- **Palette:** paper `#F6F7F9`, canvas `#EEF0F8`, surface `#FFFFFF`, hairline `rgba(31,31,31,.10)`,
  ink `#1F1F1F`/`#5F6368`/`#9AA0A6`. **Gemini gradient `linear(100deg,#4285F4,#9B72CB,#D96570)` is
  the ONLY chromatic source.** Tracks (OA/OT/PSA) differ by gradient position + label, not hues.
  Per-stop deep text shades: blue `#0C447C`/`#1A5FB4`, purple `#4A2C7A`/`#6A4A9A`, rose `#A33B52`/`#C0496A`.
- **Type:** full Google Sans family + a mono (analog: Inter + JetBrains Mono until Google Sans is
  licensed/self-hosted; consumers read CSS vars so swap is painless). No serif.
- **Gradient intensity = MAXIMAL/IMMERSIVE but motion CALM** — governing principle "immersive
  colour, calm motion": gradient is big as atmosphere (tinted canvas + drifting mesh blobs +
  gradient hero panels + tonal cards) but motion is slow + GPU-cheap. NO fluid sim / liquid tiles /
  scroll-jacking (the old FX the user hated).
- **Animated gradient surface (canonical):** gradients ANIMATE within each element's rounded
  borders (overflow-clipped) — "abstract motion gradient", ~4–4.5s linear, full
  blue→purple→rose→blue sweep, `background-size` ~200–300%, animate `background-position`/`transform`
  only. **Frozen under reduced-motion.** Reading surfaces (chat/message areas) stay calm.
- **Logo = "Spark Eye": MONOCHROME, STATIC, NO BACKGROUND.** Eye almond outline
  `M4 24 Q24 7 44 24 Q24 41 4 24 Z` (stroke ~3, no fill) + a 4-point spark glint pupil; at ≤32px the
  spark becomes a solid pupil dot. Ink `#15161B` on light / `#FFFFFF` on dark (ideally
  `currentColor`). The mark is black&white **(logo only — the app keeps full Gemini colour)**.
  Replaces ALL placeholders (rail wordmark, login, favicon, app icon, chat avatar, loading, PWA).
- **Icon scope:** realistic imagery for brand/feature art; **small controls = clean vector glyphs**.
- **Imagery:** ALL realistic eye imagery generated via **Gemini Nano Banana Pro**, model
  **`gemini-3-pro-image`** (the "best Nano Banana model"; already `NB_MODEL` default in
  `tools/media/generate_accents.py`), using the existing **`GEMINI_API_KEY` in `.env`** (no new
  key). Verify the exact model id via ListModels before each run (ids drift). Realistic imagery
  always sits in dark "plate" wells. Generation is PAID + user-gated.
- **Navigation:** **Atlas Rail** (persistent left rail; groups STUDY / INSIGHT / role-gated
  OVERSIGHT; top strip ⌘K command palette + streak + profile; collapses to a bottom bar on mobile)
  PLUS **Atlas Map** (spatial realistic-eye region menu) used ONLY inside the **Cases** screen.
- **Tutor (chat) background = lavender wash** `linear-gradient(160deg,#EAEBFB,#EFEAF6 52%,#F6ECF1)`;
  calm white bubbles; colour only in animated accents; user bubbles soft blue/purple tint.
- **Tech approach CONFIRMED:** keep Next 16 + Tailwind v4 + FastAPI + login; rebuild every screen
  fresh; **strip the legacy `src/fx/` layer** (fluid sim, liquid tiles, preloader, Lenis, R3F);
  GSAP stays (one shared ticker drives the gradient loop).
