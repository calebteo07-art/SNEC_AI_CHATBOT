## 2. SESSION GOAL
Remove runtime AI from **content generation** in three features and replace it with large,
pre-authored, KB-grounded static pools that rotate per-user with no repeats until exhausted.
Runtime must be 100% deterministic (no Gemini call) for generating: check-in questions,
cases, and flashcards. **Grading/scoring stays AI** (case scoring, debrief, flashcard
free-text answer-check, tutor chat, patient roleplay) — EXCEPT check-in, which becomes MCQ
and is therefore graded deterministically (no AI). Content authoring itself is done at
BUILD time by AI, grounded strictly in the KB/DB, in batches the user reviews/approves
before shipping. Driver: predictable, exam-aligned content + zero AI cost/quota/latency on
these surfaces; part of the IELA 2026 award push.
